# Unterrichts-Artefakte

Interaktive Materialien (HTML) für den Informatik-Unterricht an der Berufsschule.

**Online:** https://frau-root.github.io/unterricht-artefakte/

## Aufbau

Jedes Artefakt liegt in einem eigenen Ordner mit einer `index.html`:

```
thema-kurzname/index.html   →  https://frau-root.github.io/unterricht-artefakte/thema-kurzname/
```

Die Startseite `index.html` verlinkt alle Artefakte.

## Regel

Dieses Repository ist **öffentlich**: keine Schülernamen, Noten, Fotos von Schüler:innen
oder andere personenbezogene Daten.
